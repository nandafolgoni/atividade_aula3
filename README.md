# 🎨 Atividade Aula 3 — Tipografia e Cores

> **Atividade de Pesquisa | Linguagem de Marcação**

Este repositório contém o resultado da atividade de pesquisa sobre **Tipografia e Cores**, desenvolvida para o curso de **Técnico de Desenvolvimento de Sistemas**.

O objetivo da atividade é analisar dois sites reais e identificar como princípios de **tipografia, cores, contraste, hierarquia visual, organização e experiência do usuário (UX)** influenciam a qualidade de uma interface.

---

## 📌 Objetivo

A pesquisa foi dividida em dois exemplos:

* ✅ **Exemplo BOM:** um site que apresenta boas práticas de design, tipografia, cores e organização visual.
* ❌ **Exemplo RUIM:** um site que apresenta problemas relacionados à harmonia visual, hierarquia, contraste ou excesso de elementos.

A comparação permite compreender, na prática, como decisões de design podem melhorar ou prejudicar a experiência do usuário.

---

## 🔎 Sites analisados

### ✅ Exemplo BOM — Unseen Studio

**Site:** https://unseen.co/

A **Unseen Studio** foi escolhida como exemplo positivo por apresentar uma identidade visual organizada e coerente.

### Pontos positivos analisados

* Hierarquia tipográfica clara;
* Uso consistente da tipografia;
* Boa organização das informações;
* Espaçamento adequado entre elementos;
* Identidade visual coerente;
* Boa combinação entre cores e elementos gráficos;
* Experiência visual alinhada à proposta criativa do estúdio.

---

### ❌ Exemplo RUIM — LINGsCARS

**Site:** https://customer.lingscars.com/

A **LINGsCARS** foi escolhida como exemplo negativo devido à grande quantidade de elementos visuais presentes na interface.

### Principais problemas identificados

* Poluição visual;
* Excesso de elementos na página;
* Uso intenso de diferentes cores;
* Hierarquia tipográfica pouco clara;
* Muitos elementos competindo pela atenção;
* Dificuldade para localizar rapidamente as informações principais.

### Possíveis melhorias

Para melhorar a interface, seria possível:

* Reduzir elementos decorativos;
* Diminuir a quantidade de cores utilizadas simultaneamente;
* Criar uma escala tipográfica consistente;
* Aumentar o espaçamento entre as seções;
* Destacar somente as informações mais importantes;
* Organizar produtos e preços em componentes visuais padronizados.

---

## 📊 Comparação

| Critério              | Unseen Studio                     | LINGsCARS                                           |
| --------------------- | --------------------------------- | --------------------------------------------------- |
| **Tipografia**        | Hierarquia clara e organizada     | Muitos elementos competindo pela atenção            |
| **Cores**             | Mais consistentes e controladas   | Uso visual muito intenso                            |
| **Hierarquia visual** | Boa organização das informações   | Muitos elementos possuem destaque                   |
| **Espaçamento**       | Ajuda na leitura                  | Maior sensação de excesso                           |
| **Organização**       | Estrutura visual clara            | Grande quantidade de informações                    |
| **UX**                | Experiência criativa e organizada | Navegação pode ser prejudicada pela poluição visual |

## 🎓 Conclusão

A análise demonstra que **tipografia, cores, espaçamento e hierarquia visual** possuem influência direta na experiência do usuário.

A Unseen Studio apresenta uma composição mais organizada e consistente, enquanto a LINGsCARS utiliza uma quantidade muito maior de elementos visuais, tornando a leitura e a localização das informações menos imediatas.

A pesquisa permite compreender que um bom design não depende apenas de elementos visualmente chamativos, mas principalmente de **organização, legibilidade, contraste, hierarquia e coerência visual**.
